# 员工手册（WorkMate 制度知识库）

本手册是公司内部制度的标准口径，回答员工关于考勤、请假、报销、福利、IT 支持等问题时以本手册为准。

---

## 一、年假制度

1. **年假天数**：入职满 1 年享 5 天年假，之后每满 1 年增加 1 天，上限 15 天。
2. **使用规则**：年假可分段使用，最小单位为半天（0.5 天）。
3. **顺延规则**：当年未休完的年假可顺延至次年 3 月 31 日，逾期自动作废，不作经济补偿。
4. **离职结算**：离职时剩余年假按日工资折算补偿。

## 二、报销制度

1. **报销类别**：交通（transport）、餐饮（meal）、住宿（lodging）、办公用品（office）、差旅（travel）、其他（other）。
2. **发票要求**：需提供增值税发票，抬头为「XX 科技有限公司」；电子发票需附验证码。
3. **差旅标准**：
   - 住宿：一线城市每晚不超过 500 元，其他城市 350 元；
   - 餐饮：每日不超过 120 元；
   - 交通：优先高铁二等座 / 经济舱。
4. **报销流程**：OA 系统提交报销单 → 直属上级审批 → 财务审核 → 15 个工作日内打款。
5. **报销时限**：费用发生后 30 天内提交，逾期原则上不予受理。

## 三、考勤制度

1. **工作时间**：标准工时 9:00–18:00，午休 12:00–13:00，弹性上下班各 1 小时。
2. **迟到**：每月迟到 3 次以内不扣款，超过部分按 50 元/次从工资扣除。
3. **加班**：加班需提前申请，工作日加班按 1.5 倍工资，周末 2 倍，法定节假日 3 倍。
4. **打卡**：使用公司 OA / 门禁打卡，忘打卡需当天补卡。

## 四、请假制度

1. **事假**：按日工资扣除，需提前 1 天申请。
2. **病假**：3 天以内凭医院证明不扣工资，超过 3 天按病假工资标准（70%）发放。
3. **婚假**：3 天；**产假**：98 天；**陪产假**：15 天。
4. **请假流程**：OA 系统提交请假申请 → 直属上级审批 → 超过 3 天需部门负责人加签。

## 五、福利政策

1. **社保公积金**：五险一金 + 补充商业保险（含门诊报销）。
2. **年度体检**：每年一次，公司统一组织，可携带 1 名家属（自费）。
3. **团建经费**：每年每人 1000 元，以部门为单位申请。
4. **节日福利**：春节、中秋、端午发放节日礼包或购物卡。

## 六、IT 支持

1. **设备申请**：新员工入职统一配置 MacBook Pro；办公显示器、键盘等可申请。
2. **远程办公**：使用公司 VPN 连接内网，账号由 IT 统一开通。
3. **账号管理**：企业邮箱、OA、IM 账号在入职当天开通；离职时统一回收。
4. **故障报修**：IT 支持通过 OA「IT 工单」提交，响应时限 4 小时内。

---

*以上制度口径以最新版本为准，如有冲突请咨询 HR / 行政 / IT 部门。*
