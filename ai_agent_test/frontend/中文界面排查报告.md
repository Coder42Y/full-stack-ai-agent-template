# WorkMate 前端中文化排查报告

> 日期：2026-08-14
> 项目：`ai_agent_test/frontend`（WorkMate 企业员工 AI 助手）

## 一、问题根因

中文界面残留英文的三大来源：

1. **zh.json 缺失 i18n key**：i18n 采用「en.json 为基础 + zh.json 覆盖」的 merge 机制，zh 未覆盖的 key 直接 fallback 显示英文。修复前 zh 仅有 243/517 个 key。
2. **硬编码英文**：大量组件/页面直接写死英文文本，未走 `useTranslations`，即使有 key 也不生效（40+ 文件、数百处）。
3. **落地页 `LANDING_COPY.zh` 残留**：demo rows / Expenses this month / Employees 等。

另外发现：`LANDING_COPY.en`（英文界面）仍是旧 MobilityOps 共享出行内容；marketing 营销页（about/community/help/contact/legal/security/changelog）文案是模板自带的「SaaS 创始人向」内容。

## 二、修复内容

### 阶段 1：zh.json 补齐（0 缺失）
- 补齐全部 **517 个 key** 的中文，含模板预置 namespace（admin/errors/footer/invitations/knowledgeBases/members/organizations/profile）。
- **营销页按 WorkMate 语境改写**（about/changelog/community/contact/help/legal/security/blog/cookies），去掉「SaaS 模板/创始人」叙事，改成企业员工助手定位。

### 阶段 2：硬编码英文接入 i18n
- **9 个并行子代理**按模块处理：admin / billing / settings / orgs+teams+kb+rag / chat / auth+onboarding / layout+states+error / marketing+legal+changelog。
- 合计新增 **947 组 key**（en+zh 对称），修改 **40+ 文件**。
- 落地页 `LANDING_COPY.zh` 残留、`LANDING_COPY.en` 整体适配 WorkMate。
- legal 页面新增中文正文（TermsBodyZh / PrivacyBodyZh / CookiesBodyZh），changelog 数据中文化（5 条 WorkMate 版本记录）。
- 我手动处理：dashboard 5 组件（recent-activity/team-summary/tool-usage/top-models/usage-timeline）、theme-toggle、usage-gauge、org-switcher、subscription-chip、settings-nav、orgs 页 tier 映射、billing hero、about 统计值。

### 阶段 3：Build + 修复类型错误
修复了子代理引入的 7 处类型错误：`t.rich` 富文本标签语法（next-intl 3.x 需 `<em>` 而非 `{em}`）、`t` 未定义/重复声明、可选链、`useFormatter` 签名、`t.locale` → `useLocale` 等。

## 三、验证结果

本地 `bun start` + 浏览器实测，以下页面中文界面均无英文残留：
- 落地页、登录页（brand 面板）、忘记密码页
- dashboard（系统状态/方案/org 标签/工具统计全中文）
- chat（智能分析）、billing（用量）+ 子页、admin + 子页、kb、settings（侧边栏）、orgs
- 营销页：about / pricing / changelog / help / contact / legal（中文条款）

## 四、合理保留的英文（非残留）

| 位置 | 原因 |
|---|---|
| `global-error.tsx` / `not-found.tsx` | 在 `[locale]` 外，无 locale 上下文，强行接入有运行时风险（next-intl 官方建议） |
| `opengraph-image.tsx` | OG 社交分享图品牌文案 |
| `dialog.tsx` / `sheet.tsx` | `sr-only` Close（仅屏幕阅读器，视觉不可见） |
| 后端返回数据 | 模型名（deepseek-v4-flash）、工具名（Mcp Execute Query）、provider（openai）、org/plan 数据、额度交易描述 |
| 技术名词 | MCP / PostgreSQL / SQL / ECharts / bge / pgvector |
| `language-switcher.tsx` | aria 中英混合「Language / 语言」（设计如此） |
| legal 英文正文组件 | 英文版保留给英文界面（有中文版 TermsBodyZh 等） |
| `LANDING_COPY.en` | WorkMate 英文版文案（英文界面用） |

## 五、遗留建议

1. `admin.stubBannerDesc` 内 `'{id}'` 用 ICU 撇号转义，功能正常，可后续简化。
2. orgs 页个人 org 显示「个人」标题 +「当前」badge（已无重复）。
3. 英文界面（`/en`）的营销页内容已 WorkMate 化，可后续抽查英文翻译质量。
4. 后端部分错误消息、seed 数据（如 org 名 "Personal"）为英文，如需彻底中文化需改后端。

## 六、关键文件

- `messages/zh.json`（517+ 补丁 key 全量中文）
- `src/i18n.ts`（merge 机制）
- 各 `src/components/*`（useTranslations 接入）
- `src/app/[locale]/page.tsx`（LANDING_COPY zh/en 均 WorkMate 化）
